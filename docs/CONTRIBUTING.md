# 🛠️ GENKIT AI — Developer Guidelines & Standards

## Coding Standards
1. **Line Limit**: Maximum **300 lines of code** per file (except `decoder.py`).
2. **Function Limit**: Maximum **50 lines of code** per function.
3. **Type Annotations**: 100% type hint coverage.
4. **Code Quality Commands**:
   - `flake8 backend/app`
   - `black backend/app`
   - `mypy backend/app`
